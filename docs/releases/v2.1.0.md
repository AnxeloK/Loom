# Loom 2.1.0

This release improves runtime correctness, Paper compatibility, and tick performance for Minecraft 26.2.

Chunk generation now retains surrounding chunks while post processing runs. This prevents fluids and neighbour updates at chunk borders from forcing a synchronous chunk load and stopping the server.

Plugin tasks, callbacks, portals, and chunk publication now resume through the correct owner domain while preserving execution order. Paper fields and entry points used by existing plugins have also been restored and checked during every build.

Random ticking now skips sections with no eligible work. Entity push checks use tighter search bounds, while region lookups and chunk tick batching create fewer temporary objects.

Requires Java 25 or newer.
