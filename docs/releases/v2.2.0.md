# Loom 2.2.0

This prerelease targets Minecraft 26.3 and requires Java 25 or newer. Its pinned
Paper base is a beta build.

Player data, statistics and advancement files are prepared outside login ticks.
Periodic saves, logout writes and reconnect reads use an ordered per-player I/O
queue. Live player changes and advancement listeners remain on their owners.

Region-aware plugin declarations now select native callback routing through the
shared Paper scheduling API. Existing ownership checks and compatibility
escalation remain active. Plugin authors can use entity, location, global and
async schedulers across supported runtimes.

The entity-wrapper registry initializes during startup before connections are
accepted, moving its first-use class loading away from the first player's login.

Back up worlds, player files and plugin data before upgrading from Minecraft
26.2. Keep the pre-upgrade data set for rollback. Plugins that use server internals
need a matching 26.3 build.
