# Loom 2.0.7

This release simplifies compatibility routing and replaces the project documentation with shorter guides for running and diagnosing a server.

## Changes

- Compatibility routing now follows one automatic policy.
- `/loom compatibility` now reports forced serialized fallback paths by name.
- Setup, first-run checks, diagnostics, performance tuning, architecture, and contribution guides have been rewritten.

## Downloads

Choose the jar that matches the exact Minecraft version on your server.
