# Security Policy

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities.

Use one of the following:

- GitHub Security Advisory for this repository (preferred)
- Private contact with the maintainer if advisory flow is unavailable

Include:

- affected version or commit
- reproduction steps
- expected vs actual behavior
- impact assessment

## Scope

Security reports are prioritized for:

- remote code execution
- privilege escalation
- authentication or session bypass
- data exposure
- denial-of-service vectors in runtime ownership or compatibility paths

## Coordinated Disclosure

Please allow time for triage and a fix before public disclosure.
After remediation, coordinated public disclosure is welcome.
